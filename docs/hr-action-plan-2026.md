# 人事アクションプラン 2026年度(2026年7月〜2027年6月)再構築案

元のアクションプラン表をベースに、以下の観点で再構築したもの。

1. 大項目の上位に「人事としてつくりたい状態」を明文化
2. 大項目 → 中項目 → 小項目 の3階層に再編し、粒度を統一
3. ゴールの積み上げ関係を担保(小項目ゴールを全て達成すると中項目ゴールが達成、中項目ゴールを全て達成すると大項目ゴールが達成)
4. 小項目にも背景・目的・ゴールを設定(ゴールには必ず時間軸を明記)
5. 重なりのある項目を「設計/運用」「対象別」「プロセス別」などの軸で分解し直し
6. ゴールを「人事がコントロール可能な状態」に統一(事業成果・社員の心情は目的に置き、ゴールにはしない)

---

## 0. 最上位:人事1年目のミッション

> **2027年6月末(人事1年目終了)時点で、「伝わる・報われる・揃う・つながる・育つ」の5つの人事基盤が設計・稼働しており、社員が「この会社で正しく努力すれば、正しく評価され、成長できる」と信じられる土台ができている状態。**

この最上位ゴールを、以下の5つの大項目に分解する(旧「新組織における業務円滑化」と「新組織の統制」は、どちらも"新組織を機能させる"ことが本質で重なりが大きいため、「組織開発」として統合した)。

## 4. 「人事としてのゴール」の考え方(今回の再定義方針)

ゴールはすべて**人事がコントロール可能な状態**(制度・仕組み・体制が「設計され・開示され・運用されている」)に揃えた。事業成果や社員の心情は、人事施策の結果として得たいもの=**目的**に置き、ゴールからは外している。

主な再定義の例:

| 元のゴール表現 | 問題点 | 再定義 |
|---|---|---|
| 「揉め事なくプロジェクトが円滑に回っている状態」(役割・責任の明確化) | 事業運営側の成果であり、人事が直接コントロールできない | 人事のゴールは「標準プロセス・役割・エスカレーションルールの明文化と関係部門の合意まで」。円滑な運営は目的に記載 |
| 「全社員がミッションを自分ごととして捉え、高いエンゲージメントを持って前向きに業務に取り組めている状態」(エンゲージメント) | 社員の心情そのものはコントロール不能で、達成判定もできない | 人事のゴールは「浸透の場の定例運営」と「サーベイによる測定・改善サイクルの実行」。心情の変化は目的+サーベイの観測指標 |
| 「連携しやすくなったと実感できている状態」(全社会議) | 実感は測定手段がなければ判定できない | 人事のゴールは「新しい全社会議の開始と定例運営」。実感はエンゲージメントサーベイで観測 |
| 「12月末までにすべての対象ポジションで内定承諾」(欠員補充) | これは人事のゴールとして適切(そのまま採用) | 変更なし。ただし入社後の定着・戦力化は「オンボーディング」のゴールで受ける、と役割分担を明確化 |
| 「2〜3ヶ月で自立して業務を行える状態」(オンボーディング) | 自立までの期間は本人・職種にも依存する | 人事のゴールは「プログラムの設計と対象者全員への適用」。2〜3ヶ月での自立は目的に置き、適正水準は運用で検証 |
| 「全社員が納得して設定できている状態」(目標の接続) | 納得は社員の心情であり、人事が直接コントロールできない | 人事のゴールは「接続フロー・フォーマットの確定」と「人事主導での目標設定運用の完走」。納得感は目的に置き、サーベイ等で観測 |
