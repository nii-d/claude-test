# Notion へのインポート手順

所要時間: 15〜20分

---

## 1. ページをインポートする

1. Notion を開き、左サイドバー下部の **「インポート」** をクリック
2. **「Markdown & CSV」** を選ぶ
3. `全社SharePointマニュアル_Notionインポート用.zip` をアップロード
4. 完了すると、サイドバーに **「全社SharePointマニュアル」** が1ページとして作られ、その配下に子ページが入ります

### インポート後の階層

```
全社SharePointマニュアル
├ A1 はじめに
├ A2 情報の置き場所ルール
├ A3 サイト一覧の見方
├ A4 各サイトの詳細
│  ├ 01 WorkBase
│  ├ 02 knowledge
│  ├ 03 社長室
│  ├ 04 法人事業部
│  ├ 05 スクール事業部
│  ├ 06 研修・講師統括部
│  ├ 07 デジタル開発部
│  ├ 08 管理部
│  ├ 09 正本置き場
│  ├ 10 案件管理
│  └ 11 ビジネスパートナー
├ A5 ファイルの扱い方
├ A6 依頼と問合せのしかた
├ B1 サイトアーキテクチャ設計
├ B2 権限とグループ設計
├ B3 依頼受付の仕組み
├ B4 移行計画
└ B5 決めること一覧
```

## 2. データベースをインポートする

`サイト一覧_DB.csv` と `依頼タスクDB_テンプレート.csv` は**別々にインポート**します。

1. 「インポート」→「Markdown & CSV」→ CSVファイルを選択
2. 新しいデータベースとして作成されます
3. **プロパティの型はすべてテキストとして取り込まれるため、手動で設定し直してください**（下記）

### サイト一覧_DB の型設定

| プロパティ | 設定する型 |
|---|---|
| サイト名 | タイトル |
| URL | URL |
| エリア | セレクト |
| 責任部署 | セレクト |
| 想定読者 | テキスト |
| 秘密度ラベル | セレクト |
| 最終棚卸し日 / 次回見直し期限 | 日付 |
| その他 | テキスト |

### 依頼タスクDB の型設定

| プロパティ | 設定する型 |
|---|---|
| 件名 | タイトル |
| 依頼元部署 / 宛先部署 / 宛先課 / 依頼種別 / 緊急度 / 公開区分 | セレクト |
| **ステータス** | **ステータス**（未受付／受付済／対応中／確認待ち／完了／差戻し／対象外） |
| 担当者 | ユーザー |
| 希望納期 / 約束納期 / 完了日 | 日付 |
| 関連リンク | URL |

さらに次を追加してください。

- **依頼ID**: ID型（自動採番）
- **受付日**: 作成日時型
- **期限超過**: 数式型 — `約束納期 < today()` かつ ステータスが「完了」以外

サンプル行が2行入っています。**確認後に削除してください。**

## 3. インポート後に必要な手直し

**Notion のインポートでは、トグルとカラー付きコールアウトは生成されません。** 次の3つは手作業になります。

| # | 作業 | 方法 |
|---|---|---|
| 1 | 長い章を折りたためるようにする | 見出しブロックを選択 → 「⋮⋮」→ ブロックタイプの変更 → **トグル見出し** |
| 2 | 重要な注意書きを目立たせる | 引用（`>`）で入っている箇所を **コールアウト**に変換 |
| 3 | Mermaid図を表示する | コードブロックを選択 → 右上の表示切替で **プレビュー** にする |

### Mermaid図が入っている場所

| ページ | 図 |
|---|---|
| 全社SharePointマニュアル（親） | サイトの全体像 |
| A6 依頼と問合せのしかた | 依頼の流れ |
| B1 サイトアーキテクチャ設計 | サイト構成の全体図 |
| B3 依頼受付の仕組み | 依頼受付の構成 |
| B4 移行計画 | 移行スケジュール、資料を維持する仕組み |
| 09 正本置き場 | 改訂の流れ |

## 4. 公開範囲の設定

1. 親ページ「全社SharePointマニュアル」を開く
2. 右上の **「共有」** → ワークスペース全体に **「フルアクセス」ではなく「閲覧のみ」** で共有
3. 編集権限は管理部のメンバーと各部のサイトオーナーにのみ付与

> 全社員に編集権を配ると、意図しない変更が入っても誰がいつ変えたか追いにくくなります。

## 5. SharePoint 側からのリンク

1. 親ページのURLをコピー（右上「⋮」→「リンクをコピー」）
2. WorkBase サイトのホームに、クイックリンクWebパーツで「全社マニュアル」として設置

> **Notion のページを SharePoint に埋め込むことはできません**（Notion側がiframe埋め込みを制限しているため）。リンクでの遷移になります。

## 補足: 更新はどちらで行うか

インポート後は **Notion 側が正**になります。このzip内のMarkdownは初期投入用であり、以後の更新はNotion上で行ってください。

年1回（4月）の棚卸しで内容を見直し、確定版を「正本置き場 / 03_全社マニュアル」にPDFで保存する運用を推奨します。
