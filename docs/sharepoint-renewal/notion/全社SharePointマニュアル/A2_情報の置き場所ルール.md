# A2 情報の置き場所ルール

**誰向け**: 全社員（**必読**）
**所要時間**: 3分
**この章の結論**: 残すものはSharePoint、進めるものはNotion、話すことはTeams、自分用はOneDrive。

---

## 1行ルール

> **これは「残す」ものか、「進める」ものか、「話す」ことか。**

| 判定 | 置き場所 |
|---|---|
| **残す** — 後から誰かが探しに来るもの | **SharePoint** |
| **進める** — 期限と担当がついているもの | **Notion** |
| **話す** — その場のやりとり | **Teams** |
| **自分用** — まだ人に見せる段階でないもの | **OneDrive** |

## それぞれに置くもの・置かないもの

### SharePoint（残す）

- **置く**: 確定したファイル、規程、様式、マニュアル、成果物、議事録、部署の案内ページ
- **置かない**: 進行中のタスク、期限と担当の管理、会話、自分だけが使う作業メモ

### Notion（進める）

- **置く**: 他部署への依頼、その進捗・期限・担当、タスクの状況
- **置かない**: 大きなファイルの保管、正本のファイル（SharePointのリンクを貼る）

### Teams（話す）

- **置く**: 相談、質問、日々の連絡、会議
- **置かない**: **正本ファイルの添付**。チャットに添付すると、どれが最新か分からなくなります。SharePointに置いてリンクを貼ってください

### OneDrive（自分用）

- **置く**: 下書き、思考中のメモ、自分だけが使う一時ファイル
- **置かない**: 他人が探しに来る可能性のあるもの。**あなたが休んだ日に誰も開けません**

---

## よくある判断に迷うケース

| ケース | 正解 | 理由 |
|---|---|---|
| 会議の議事録 | SharePoint（部の公開または限定ライブラリ） | 後から探される |
| 会議で決まったToDo | Notion | 期限と担当がある |
| 提案書の作りかけ | OneDrive → 完成したらSharePoint | 途中を人に見せる必要がない |
| 経費規程の最新版 | 正本置き場（部サイトには置かない） | 正本はひとつだけ |
| 経費精算のやり方の説明 | knowledge | 規程の「読み方」は解説であって正本ではない |
| 顧客からもらった資料 | 案件管理サイトの案件コードのフォルダ | 案件単位で探される |
| 他部署への作業依頼 | Notion（依頼Formから） | 期限と担当がある |
| 「これ知ってる人いますか」 | Teams | 会話 |

---

## やってはいけないこと

1. **Teamsのチャットに正本ファイルを添付する** — 版が分岐します。SharePointのリンクを貼ってください。
2. **自分のOneDriveに、他人が必要とするファイルを置く** — あなたが不在の日に業務が止まります。
3. **同じファイルを複数のサイトにコピーする** — どちらが最新か分からなくなります。リンクを貼ってください。
4. **フォルダを3階層以上作る** — 誰も辿り着けません。2階層までにして、あとは列（メタデータ）で分類してください。
5. **ファイル単位・フォルダ単位で個別に権限をつける** — 半年後に誰も権限の全体像を説明できなくなります。権限はライブラリ単位までです。
