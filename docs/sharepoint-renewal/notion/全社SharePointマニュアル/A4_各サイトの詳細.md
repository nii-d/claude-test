# A4 各サイトの詳細

**誰向け**: 各部のサイト管理者、情報を探している全社員
**所要時間**: 自部署のページのみなら5分
**この章の結論**: 11サイトすべてを同じ7項目で記述している。自部署のページを見て、実態と違えば修正すること。

---

## 各ページの読み方

11サイトすべてが、次の7項目で統一されています。

| 項目 | 意味 |
|---|---|
| 1. 何のための場所か | このサイトの存在理由を1文で |
| 2. 責任と読者 | 責任部署、サイトオーナー、想定読者、閲覧範囲 |
| 3. **書かれていること** | ページの一覧と、各ページの中身 |
| 4. **置かれているもの** | ライブラリの一覧と、中身・権限 |
| 5. **置かないもの** | ここに置いてはいけないものと、代わりの置き場所 |
| 6. 問合せ窓口 | 困ったときの連絡先 |
| 7. 更新ルール | 誰がいつ見直すか |

## 各部への確認のお願い

**04〜08の部サイトは、私（管理部）が想定で下書きしたものです。** 各部のサイトオーナーは次を確認してください。

- [ ] 「1. 何のための場所か」が部の実態と合っているか
- [ ] 「3. 書かれていること」の課ページが、実際の課の数と名前に合っているか
- [ ] 「4. 置かれているもの」に、その部でしか使わないライブラリが必要ないか
- [ ] 「5. 置かないもの」に、実際にありがちな誤配置が入っているか
- [ ] 「6. 問合せ窓口」のTeamsチャネル名が正しいか

修正は依頼Form（宛先＝管理部・種別＝マニュアル修正）から。
