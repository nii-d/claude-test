# A3 サイト一覧の見方

**誰向け**: 全社員
**所要時間**: 3分
**この章の結論**: 社外秘エリアに10サイト、関係者外秘エリアに1サイト。詳細はA4の各ページ。

---

## 全11サイト

### 社外秘エリア（WorkBase 配下）

| サイト | 責任部署 | 何のための場所か | 全社員から見えるもの |
|---|---|---|---|
| **WorkBase** | 管理部 | 全社の入口。ここから各サイトへ行く | すべて |
| **knowledge** | 管理部 | 業務のやり方・解説・ノウハウ | すべて |
| **社長室** | 社長室 | 経営方針と全社通達の発信 | 公開ライブラリのみ |
| **法人事業部** | 法人事業部 | 法人向け事業の情報と成果物 | 公開ライブラリのみ |
| **スクール事業部** | スクール事業部 | スクール事業の情報と成果物 | 公開ライブラリのみ |
| **研修・講師統括部** | 研修・講師統括部 | 研修運営と講師管理の情報 | 公開ライブラリのみ |
| **デジタル開発部** | デジタル開発部 | サービス開発と社内IT の情報 | 公開ライブラリのみ |
| **管理部** | 管理部 | 総務・人事・経理の情報 | 公開ライブラリのみ |
| **正本置き場** | 管理部（運用）／各部（内容） | 規程・様式の最新確定版 | すべて（閲覧のみ） |
| **案件管理** | 法人事業部（主管）／デジタル開発部（仕組み） | 案件の成果物を案件コードで横断管理 | 公開ライブラリのみ |

## 部サイトの共通構成

法人事業部・スクール事業部・研修・講師統括部・デジタル開発部・管理部の5つは、**まったく同じ構成**です。どの部署に行っても迷いません。

### ページ（説明を書く場所）

| ページ | 何が書かれているか |
|---|---|
| ホーム | 部のミッション、業務範囲、体制図、**問い合わせボタン**、主要リンク、新着 |
| ➀課 | 課の役割、担当業務、メンバーと担当領域、定例会、標準リードタイム |
| ②課 | 同上（②課の内容） |
| 業務マニュアル案内 | 手順書の一覧（実体は knowledge にあり、ここはリンク集） |
| FAQ | その部署へのよくある質問と回答 |

### ライブラリ（ファイルを置く場所）

| ライブラリ | 誰が見られるか | 誰が編集できるか |
|---|---|---|
| `01_公開_共通` | 全社員 | その部のメンバー |
| `01_公開_➀課` | 全社員 | その部のメンバー |
| `01_公開_②課` | 全社員 | その部のメンバー |
| `02_限定_部` | その部のメンバーのみ | その部のメンバー |
| `02_限定_➀課` | その部のメンバー | ➀課のメンバー |
| `02_限定_②課` | その部のメンバー | ②課のメンバー |

先頭の `01_` `02_` は並び順を固定するためのものです。**名前の先頭に「公開」「限定」が来るので、共有する前に区別がつきます。**

## 探し方のコツ

1. **まず検索する。** SharePoint の検索窓は全サイトを横断します。権限のないファイルは出てこないので、安心して検索してください。
2. **部署から探すなら** WorkBase のナビゲーション → 部署サイト → ライブラリ。
3. **規程・様式を探すなら** 迷わず正本置き場へ。部サイトには正本を置かないルールです。
4. **やり方・手順を探すなら** knowledge へ。
5. **見つからないときは** その部署の問い合わせボタンから聞いてください。探すより早いです。
