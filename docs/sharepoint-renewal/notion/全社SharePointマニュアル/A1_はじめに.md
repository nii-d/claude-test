# A1 はじめに

**誰向け**: 全社員
**所要時間**: 2分
**この章の結論**: 迷ったら「残すのか、進めるのか、話すのか」で置き場所を決める。困ったら各部サイトの問い合わせボタン。

---

## この資料は何か

組織改編にあわせて全社SharePointを作り替えました。その結果、**どのサイトに何が書かれ、何が置かれているか**を1つにまとめたものです。

全部を読む必要はありません。**A2（情報の置き場所ルール）だけは全員読んでください。** 残りは必要になったときに逆引きで使ってください。

## 何が変わったか

これまでは、どこに何があるかが部署ごとにバラバラでした。同じ「資料」でも、ある部署ではフォルダの奥、別の部署ではTeamsのチャットの中、という状態です。**これからは全部署が同じ構成・同じ名前のライブラリになります。** 他部署のサイトに行っても、探す場所は同じです。

公開・非公開の区別も曖昧でした。「一応みんなに見せていいはず」のファイルと「部内限りのはず」のファイルが同じフォルダに入っていました。**これからはライブラリ単位で分かれ、権限で守られます。** ファイル名の先頭を見れば公開か限定かが分かるので、共有する前に気づけます。

そしていちばん変わるのが**依頼のしかた**です。これまでは部署ごとにTeamsだったりFormsだったりバラバラで、しかも依頼を出したあとそれがどうなったのか、依頼者からは見えませんでした。**これからは各部サイトの問い合わせボタンに統一され、進捗をNotionで全社員が見られます。**

## 用語

| 用語 | 意味 |
|---|---|
| **WorkBase** | 全社の入口となるトップサイト。ここから各部署のサイトへ行く |
| **ハブサイト** | 複数のサイトをまとめて、共通のナビゲーションを出す仕組み。WorkBase がこれ |
| **ドキュメントライブラリ** | ファイルを置く場所。フォルダの親にあたるもの |
| **ページ** | 説明や案内を書く場所。ファイルは置かない |
| **公開ドキュメント** | 全社員が見られるライブラリ |
| **限定ドキュメント** | 部または課のメンバーだけが見られるライブラリ |
| **正本（せいほん）** | 「これが最新で正しい」と全社が信じてよい唯一の版 |
| **秘密度ラベル** | ファイルやサイトに付ける機密区分。外部共有の可否などを自動で制御する |

## 困ったときの行き先

| 状況 | 行き先 |
|---|---|
| ファイルの置き場所が分からない | A2 情報の置き場所ルール |
| どのサイトに何があるか知りたい | A3 サイト一覧の見方 / A4 各サイトの詳細 |
| ファイル名の付け方が分からない | A5 ファイルの扱い方 |
| 他部署に作業をお願いしたい | A6 依頼と問合せのしかた |
| 見えるはずのファイルが見えない | 該当サイトのサイトオーナー（A4の各ページに記載） |
| このマニュアルの間違いを見つけた | 依頼Form（宛先＝管理部・種別＝マニュアル修正） |
