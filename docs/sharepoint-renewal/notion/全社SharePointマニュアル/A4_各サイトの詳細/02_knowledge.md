# 02 knowledge

## 1. 何のための場所か

**「どうやるか」を調べる場所。業務のやり方・ツールの使い方・社内制度の解説を集約する。**

> **正本置き場との違い**
> knowledge は**解説**（経費精算のやり方）、正本置き場は**原本**（経費規程 第4版）。
> ここを混同すると両方に同じものが置かれ、どちらが正しいか分からなくなります。

## 2. 責任と読者

| 項目 | 内容 |
|---|---|
| 責任部署 | 管理部 |
| サイトオーナー | 管理部 2名 |
| 想定読者 | 全社員（特に新入社員・中途入社者） |
| 閲覧範囲 | 全社員 |
| 編集範囲 | 全社員が記事を投稿できる（公開前に管理部が承認） |
| 秘密度ラベル | 社内限定 |
| URL | `/sites/wb-knowledge` |

## 3. 書かれていること

knowledge は**ファイルではなくページが主役**です。検索で見つかりやすく、リンクで参照しやすいためです。

| ページ分類 | 中身 |
|---|---|
| はじめての方へ | オンボーディング。入社1週間以内に読むもの |
| 業務マニュアル | 全社共通の業務手順（経費精算、勤怠、稟議、契約手続きなど） |
| ツールの使い方 | Microsoft 365（Teams / SharePoint / Forms）、Notion、その他SaaS |
| 社内制度の解説 | 各種制度の「読み方」。規程本体は正本置き場へリンク |
| 用語集 | 社内用語・略語・事業固有の言葉 |
| ナレッジ記事 | 事例、失敗事例、Tips。誰でも投稿可 |

### 記事のテンプレート

すべての記事は次の順で書きます。

1. この記事の目的（1文）
2. 対象者
3. 手順
4. よくあるつまずき
5. 関連リンク
6. **オーナー**と**最終更新日**と**次回見直し期限**

> **オーナーと見直し期限のない記事は公開しません。** 期限のないナレッジは1年で信用されなくなります。

## 4. 置かれているもの

| ライブラリ | 誰が見られるか | 中身 |
|---|---|---|
| `01_公開_共通` | 全社員 | 記事に添付する図表、手順書のPDF、動画マニュアル |
| `サイトのページ` | 全社員 | 上記のページ本体（システムが自動作成） |

## 5. 置かないもの

| 置かないもの | 代わりにどこへ |
|---|---|
| 規程・様式の原本 | 正本置き場 |
| 部署限定の手順 | 各部サイトの限定ライブラリ |
| 進行中の案件情報 | 案件管理 / Notion |
| 個人情報を含む事例 | 匿名化して記載。元データは管理部の限定ライブラリ |
