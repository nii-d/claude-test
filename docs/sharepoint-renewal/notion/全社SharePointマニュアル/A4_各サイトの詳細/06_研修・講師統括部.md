# 06 研修・講師統括部

## 1. 何のための場所か

**研修プログラムの品質と、講師の確保・育成・アサインに責任を持つ。**

## 2. 責任と読者

| 項目 | 内容 |
|---|---|
| 責任部署 | 研修・講師統括部 |
| サイトオーナー | 研修・講師統括部 部長（最終責任）／運用担当 1名（**計2名以上**） |
| 想定読者 | 全社員（公開ライブラリ）／部員（限定ライブラリ）／課員（課限定ライブラリ） |
| 閲覧範囲 | 公開ライブラリは全社員、限定ライブラリは部・課のメンバー |
| 秘密度ラベル | 社外秘 |
| URL | `/sites/wb-div03` |

> 課の名称は仮です（`➀講師管理課` / `②研修企画課`）。新組織の正式名称が決まり次第、研修・講師統括部が修正してください。

## 3. 書かれていること

| ページ | 中身 |
|---|---|
| ホーム | 部のミッション、**引き受けること・引き受けないこと**、体制図、**問い合わせボタン**、主要リンク、新着 |
| ➀講師管理課 | 講師の採用、稼働調整、評価、育成を担当。メンバーと担当領域、定例会、課への依頼窓口 |
| ②研修企画課 | 研修プログラムの設計、教材開発、品質管理を担当。メンバーと担当領域、定例会、課への依頼窓口 |
| 業務マニュアル案内 | この部が関わる手順書へのリンク集（実体は knowledge） |
| FAQ | この部へのよくある質問と回答 |

### この部が引き受けること

- 研修プログラムの内容に関する問合せ
- 講師のアサイン依頼と稼働調整
- 教材の改訂・新規開発の相談
- 研修品質に関するフィードバックの受付

### この部が引き受けないこと

- 法人顧客への提案・見積（→法人事業部）
- スクールの募集・受講者対応（→スクール事業部）
- 講師への支払処理（→管理部）

### 標準リードタイム（ホームに掲示）

| 依頼種別 | 一次回答 | 完了目安 |
|---|---|---|
| 講師アサイン依頼 | 1営業日 | 5営業日 |
| 教材の軽微な修正 | 1営業日 | 5営業日 |
| 新規プログラムの設計 | 2営業日 | 都度見積 |

## 4. 置かれているもの

| ライブラリ | 誰が見られるか | 誰が編集できるか | 中身 |
|---|---|---|---|
| `01_公開_共通` | 全社員 | 部メンバー | 研修プログラムの一覧とカリキュラム概要、講師アサインの依頼手順と締切、教材の版数一覧、部の業務フロー図と依頼受付ルール |
| `01_公開_➀講師管理課` | 全社員 | 部メンバー | 講師プロフィール（社内公開版）、アサイン可能領域の一覧 |
| `01_公開_②研修企画課` | 全社員 | 部メンバー | 教材サンプル、研修の設計方針、品質基準 |
| `02_限定_部` | 部メンバーのみ | 部メンバー | 部内会議資料、予算・実績の内訳、講師稼働の全体状況、他部と調整中の資料 |
| `02_限定_➀講師管理課` | 部メンバー | ➀講師管理課メンバー | 講師の評価記録、単価・契約条件、採用選考の記録 |
| `02_限定_②研修企画課` | 部メンバー | ②研修企画課メンバー | 開発中の教材、他社教材の分析、改訂検討中の資料 |

### フォルダとファイルの決まり

- フォルダは**第1階層＝年度、深さは2階層まで**
- ファイル名は `YYYYMMDD_文書種別_件名_v1.0.拡張子`
- 詳細は「A5 ファイルの扱い方」

## 5. 置かないもの

| 置かないもの | 代わりにどこへ |
|---|---|
| 進行中のタスクと期限 | Notion の依頼・タスクDB |
| 会話・相談 | Teams |
| 個人の作業中ファイル | OneDrive |
| 規程・様式の最新確定版 | 正本置き場 |
| 全社共通の手順書・FAQ | knowledge |
| 案件ごとの成果物 | 案件管理 |
| 講師の単価・契約条件を全社公開ライブラリに置くこと | 課限定ライブラリに限定 |
| 業務委託講師に渡す教材 | ビジネスパートナーサイト |

## 6. 問合せ窓口

| 用件 | 行き先 |
|---|---|
| 調べたい（制度・手順・様式） | この部の FAQ / knowledge / 正本置き場 |
| 相談したい（作業は発生しない） | Teams「#研修講師統括部-相談」 |
| 作業をお願いしたい（正式依頼） | ホームの**問い合わせボタン** → Notion Form（宛先＝研修・講師統括部） |
| 依頼の進捗を見たい | Notion 依頼・タスクDB |

## 7. 更新ルール

| 対象 | 誰が | いつ |
|---|---|---|
| ホーム・課ページ | 部の運用担当 | 内容が変わったとき／最低でも半期に1回 |
| FAQ | 部の運用担当 | 四半期ごと（Notionの依頼データを見て頻出を追加） |
| 標準リードタイム | 部長 | 半期ごと |
| 限定ライブラリの棚卸し | 部の運用担当 | 年1回（4月） |
| このページ自体 | 部のサイトオーナー | 年1回（4月）の全社棚卸しにあわせて |
