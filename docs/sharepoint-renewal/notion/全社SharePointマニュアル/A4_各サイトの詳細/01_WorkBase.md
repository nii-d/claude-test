# 01 WorkBase

## 1. 何のための場所か

**全社員の情報の入口。ここから3クリック以内で目的の情報にたどり着けるようにする場所。**

## 2. 責任と読者

| 項目 | 内容 |
|---|---|
| 責任部署 | 管理部 |
| サイトオーナー | 管理部 情報システム担当 2名 |
| 想定読者 | 全社員 |
| 閲覧範囲 | 全社員 |
| 秘密度ラベル | 社内限定 |
| URL | `/sites/workbase` |

## 3. 書かれていること

| ページ | 中身 |
|---|---|
| ホーム | 全社お知らせ（新着順）、全部署サイトへのナビゲーション、**依頼Formの入口**、進捗ボードへのリンク、社内カレンダー |
| 全社マニュアル | この資料そのもの（Notion版へのリンク） |
| システムリンク集 | 勤怠・経費・人事システムなど、社内で使うシステムの入口 |
| 全社お知らせ一覧 | 過去のお知らせのアーカイブ |

## 4. 置かれているもの

| ライブラリ | 誰が見られるか | 中身 |
|---|---|---|
| `01_公開_全社共有` | 全社員 | 全社会議の資料、全社通達の配布物、組織図、社内カレンダーの元データ |
| `サイトの資産` | 全社員 | ページで使う画像・ロゴ（システムが自動作成） |

## 5. 置かないもの

| 置かないもの | 代わりにどこへ |
|---|---|
| 部署固有のファイル | 各部サイト |
| 規程・様式の実体 | 正本置き場 |
| 業務の手順書 | knowledge |
| 案件の資料 | 案件管理 |

## 6. 問合せ窓口

- 依頼Form（宛先＝管理部・種別＝サイト/システム）
- Teams: 全社チーム「#情報システム」

## 7. 更新ルール

| 対象 | 誰が | いつ |
|---|---|---|
| 全社お知らせ | 社長室・管理部 | 都度 |
| ナビゲーション | 管理部 | 組織改編時 |
| システムリンク集 | 管理部 | 半期ごと |
| 全社マニュアル | 管理部 | 年1回（4月） |
