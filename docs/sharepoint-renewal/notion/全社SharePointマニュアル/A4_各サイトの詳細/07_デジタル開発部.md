# 07 デジタル開発部

## 1. 何のための場所か

**自社サービスの開発と、社内ITの整備・運用に責任を持つ。**

## 2. 責任と読者

| 項目 | 内容 |
|---|---|
| 責任部署 | デジタル開発部 |
| サイトオーナー | デジタル開発部 部長（最終責任）／運用担当 1名（**計2名以上**） |
| 想定読者 | 全社員（公開ライブラリ）／部員（限定ライブラリ）／課員（課限定ライブラリ） |
| 閲覧範囲 | 公開ライブラリは全社員、限定ライブラリは部・課のメンバー |
| 秘密度ラベル | 社外秘 |
| URL | `/sites/wb-div04` |

> 課の名称は仮です（`➀サービス開発課` / `②社内IT課`）。新組織の正式名称が決まり次第、デジタル開発部が修正してください。

## 3. 書かれていること

| ページ | 中身 |
|---|---|
| ホーム | 部のミッション、**引き受けること・引き受けないこと**、体制図、**問い合わせボタン**、主要リンク、新着 |
| ➀サービス開発課 | 自社サービスの企画・開発・運用を担当。メンバーと担当領域、定例会、課への依頼窓口 |
| ②社内IT課 | 社内システム、アカウント管理、情報セキュリティを担当。メンバーと担当領域、定例会、課への依頼窓口 |
| 業務マニュアル案内 | この部が関わる手順書へのリンク集（実体は knowledge） |
| FAQ | この部へのよくある質問と回答 |

### この部が引き受けること

- 自社サービスの不具合報告・改修要望
- 社内システムの操作方法の問合せ
- アカウント発行・権限変更の依頼
- 新規ツール導入の相談とセキュリティ確認

### この部が引き受けないこと

- サービスの営業・提案（→法人事業部）
- 業務そのものの手順設計（→各業務所管部署）
- PCの物品購入・資産管理（→管理部）

### 標準リードタイム（ホームに掲示）

| 依頼種別 | 一次回答 | 完了目安 |
|---|---|---|
| 不具合報告 | 1営業日 | 都度見積 |
| アカウント発行・権限変更 | 1営業日 | 3営業日 |
| システム改修 | 2営業日 | 都度見積 |

## 4. 置かれているもの

| ライブラリ | 誰が見られるか | 誰が編集できるか | 中身 |
|---|---|---|---|
| `01_公開_共通` | 全社員 | 部メンバー | 自社サービスの仕様概要とリリースノート、社内システムの一覧と用途、アカウント発行・権限変更の申請手順、部の業務フロー図と依頼受付ルール |
| `01_公開_➀サービス開発課` | 全社員 | 部メンバー | サービスのロードマップ（社内公開版）、リリース履歴、既知の不具合一覧 |
| `01_公開_②社内IT課` | 全社員 | 部メンバー | 社内ツールの導入状況、セキュリティルールの解説、障害の報告書 |
| `02_限定_部` | 部メンバーのみ | 部メンバー | 部内会議資料、予算・実績の内訳、開発工数の配分、他部と調整中の資料 |
| `02_限定_➀サービス開発課` | 部メンバー | ➀サービス開発課メンバー | 設計書、技術検討資料、外部ベンダとのやりとり、脆弱性の報告 |
| `02_限定_②社内IT課` | 部メンバー | ②社内IT課メンバー | ネットワーク構成、アカウント台帳、監査ログ、インシデントの詳細記録 |

### フォルダとファイルの決まり

- フォルダは**第1階層＝年度、深さは2階層まで**
- ファイル名は `YYYYMMDD_文書種別_件名_v1.0.拡張子`
- 詳細は「A5 ファイルの扱い方」

## 5. 置かないもの

| 置かないもの | 代わりにどこへ |
|---|---|
| 進行中のタスクと期限 | Notion の依頼・タスクDB |
| 会話・相談 | Teams |
| 個人の作業中ファイル | OneDrive |
| 規程・様式の最新確定版 | 正本置き場 |
| 全社共通の手順書・FAQ | knowledge |
| 案件ごとの成果物 | 案件管理 |
| 認証情報・APIキー・パスワード | ファイルに書かず、パスワード管理ツールで管理 |
| ソースコード | バージョン管理システム |

## 6. 問合せ窓口

| 用件 | 行き先 |
|---|---|
| 調べたい（制度・手順・様式） | この部の FAQ / knowledge / 正本置き場 |
| 相談したい（作業は発生しない） | Teams「#デジタル開発部-相談」 |
| 作業をお願いしたい（正式依頼） | ホームの**問い合わせボタン** → Notion Form（宛先＝デジタル開発部） |
| 依頼の進捗を見たい | Notion 依頼・タスクDB |

## 7. 更新ルール

| 対象 | 誰が | いつ |
|---|---|---|
| ホーム・課ページ | 部の運用担当 | 内容が変わったとき／最低でも半期に1回 |
| FAQ | 部の運用担当 | 四半期ごと（Notionの依頼データを見て頻出を追加） |
| 標準リードタイム | 部長 | 半期ごと |
| 限定ライブラリの棚卸し | 部の運用担当 | 年1回（4月） |
| このページ自体 | 部のサイトオーナー | 年1回（4月）の全社棚卸しにあわせて |
