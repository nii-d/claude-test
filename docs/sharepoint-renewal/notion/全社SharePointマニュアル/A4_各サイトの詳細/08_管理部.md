# 08 管理部

## 1. 何のための場所か

**総務・人事・経理・法務を担い、全社が業務に集中できる基盤をつくる。**

## 2. 責任と読者

| 項目 | 内容 |
|---|---|
| 責任部署 | 管理部 |
| サイトオーナー | 管理部 部長（最終責任）／運用担当 1名（**計2名以上**） |
| 想定読者 | 全社員（公開ライブラリ）／部員（限定ライブラリ）／課員（課限定ライブラリ） |
| 閲覧範囲 | 公開ライブラリは全社員、限定ライブラリは部・課のメンバー |
| 秘密度ラベル | 社外秘 |
| URL | `/sites/wb-div05` |

> 課の名称は仮です（`➀総務・人事課` / `②経理課`）。新組織の正式名称が決まり次第、管理部が修正してください。

## 3. 書かれていること

| ページ | 中身 |
|---|---|
| ホーム | 部のミッション、**引き受けること・引き受けないこと**、体制図、**問い合わせボタン**、主要リンク、新着 |
| ➀総務・人事課 | 採用、労務、勤怠、備品、施設、規程管理を担当。メンバーと担当領域、定例会、課への依頼窓口 |
| ②経理課 | 請求、支払、経費精算、決算、予算管理を担当。メンバーと担当領域、定例会、課への依頼窓口 |
| 業務マニュアル案内 | この部が関わる手順書へのリンク集（実体は knowledge） |
| FAQ | この部へのよくある質問と回答 |

### この部が引き受けること

- 規程・制度に関する問合せ
- 経費精算・請求・支払の問合せ
- 入退社・異動にともなう手続き
- 契約書のリーガルチェック
- 備品・施設の手配

### この部が引き受けないこと

- 各部門の業務そのものの判断（→各所管部署）
- システムの操作方法（→デジタル開発部）
- 顧客への請求内容の妥当性判断（→法人事業部）

### 標準リードタイム（ホームに掲示）

| 依頼種別 | 一次回答 | 完了目安 |
|---|---|---|
| 規程・制度の問合せ | 1営業日 | 3営業日 |
| 経費精算の差戻し対応 | 1営業日 | 3営業日 |
| 契約書のリーガルチェック | 1営業日 | 5営業日 |

## 4. 置かれているもの

| ライブラリ | 誰が見られるか | 誰が編集できるか | 中身 |
|---|---|---|---|
| `01_公開_共通` | 全社員 | 部メンバー | 各種申請の手順と締切カレンダー、経費精算・請求のルール解説、備品・施設の利用案内、部の業務フロー図と依頼受付ルール |
| `01_公開_➀総務・人事課` | 全社員 | 部メンバー | 福利厚生の案内、研修制度の案内、社内イベントの記録 |
| `01_公開_②経理課` | 全社員 | 部メンバー | 経費区分の早見表、月次締めスケジュール、支払サイトの説明 |
| `02_限定_部` | 部メンバーのみ | 部メンバー | 部内会議資料、予算・実績の内訳、他部と調整中の資料 |
| `02_限定_➀総務・人事課` | **➀総務・人事課メンバーのみ** | ➀総務・人事課メンバー | 人事評価、給与、採用選考、労務相談、健康情報 |
| `02_限定_②経理課` | **②経理課メンバーのみ** | ②経理課メンバー | 決算作業ファイル、原価の内訳、資金繰り、監査対応資料 |

> **管理部だけは課限定ライブラリを部メンバーにも見せません。** 他の4部は「部メンバーは課限定ライブラリを閲覧できる」設定ですが、
> 管理部は人事評価・給与・労務相談・健康情報を扱うため、課の外からは見えない設定にします。

### フォルダとファイルの決まり

- フォルダは**第1階層＝年度、深さは2階層まで**
- ファイル名は `YYYYMMDD_文書種別_件名_v1.0.拡張子`
- 詳細は「A5 ファイルの扱い方」

## 5. 置かないもの

| 置かないもの | 代わりにどこへ |
|---|---|
| 進行中のタスクと期限 | Notion の依頼・タスクDB |
| 会話・相談 | Teams |
| 個人の作業中ファイル | OneDrive |
| 規程・様式の最新確定版 | 正本置き場 |
| 全社共通の手順書・FAQ | knowledge |
| 案件ごとの成果物 | 案件管理 |
| 規程・様式の最新確定版 | 正本置き場（管理部が運用管理者） |
| 制度の解説記事 | knowledge |

## 6. 問合せ窓口

| 用件 | 行き先 |
|---|---|
| 調べたい（制度・手順・様式） | この部の FAQ / knowledge / 正本置き場 |
| 相談したい（作業は発生しない） | Teams「#管理部-相談」 |
| 作業をお願いしたい（正式依頼） | ホームの**問い合わせボタン** → Notion Form（宛先＝管理部） |
| 依頼の進捗を見たい | Notion 依頼・タスクDB |

## 7. 更新ルール

| 対象 | 誰が | いつ |
|---|---|---|
| ホーム・課ページ | 部の運用担当 | 内容が変わったとき／最低でも半期に1回 |
| FAQ | 部の運用担当 | 四半期ごと（Notionの依頼データを見て頻出を追加） |
| 標準リードタイム | 部長 | 半期ごと |
| 限定ライブラリの棚卸し | 部の運用担当 | 年1回（4月） |
| このページ自体 | 部のサイトオーナー | 年1回（4月）の全社棚卸しにあわせて |
