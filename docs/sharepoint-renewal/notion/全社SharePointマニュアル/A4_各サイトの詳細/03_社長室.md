# 03 社長室

## 1. 何のための場所か

**経営の意思と全社方針を発信する場所。あわせて経営会議の資料を限定管理する。**

## 2. 責任と読者

| 項目 | 内容 |
|---|---|
| 責任部署 | 社長室 |
| サイトオーナー | 社長室 2名 |
| 想定読者 | 全社員（公開ライブラリ）／社長室メンバー（限定ライブラリ） |
| 閲覧範囲 | 公開ライブラリは全社員、限定ライブラリは社長室メンバーのみ |
| 秘密度ラベル | 社外秘 |
| URL | `/sites/wb-exec` |

## 3. 書かれていること

| ページ | 中身 |
|---|---|
| ホーム | 社長メッセージ（最新）、経営方針、全社通達の新着、**問い合わせボタン** |
| 経営方針 | 中期経営計画の要旨、今期の全社目標、進捗の全社共有 |
| 全社通達一覧 | 過去の通達のアーカイブ（発信日・件名・対象者） |

## 4. 置かれているもの

| ライブラリ | 誰が見られるか | 誰が編集できるか | 中身 |
|---|---|---|---|
| `01_公開_共通` | 全社員 | 社長室 | 経営方針、中期経営計画、全社通達、社長メッセージ、月次の全社共有資料 |
| `02_限定_部` | 社長室メンバーのみ | 社長室 | 取締役会・経営会議の資料と議事録、資本政策、個別の人事案件、M&A関連 |

> **`02_限定_部` は他部署の部長にも見えません。** 部サイトの限定ライブラリより厳しい設定です。閲覧者を追加する場合は必ずサイトオーナーの承認を取ってください。

## 5. 置かないもの

| 置かないもの | 代わりにどこへ |
|---|---|
| 各部門の実務資料 | 各部サイト |
| 規程の原本 | 正本置き場 |
| 個人の人事評価データ | 管理部の限定ライブラリ |
| 進行中の依頼・タスク | Notion |

## 6. 問合せ窓口

- 依頼Form（宛先＝社長室）
- Teams: 全社チーム「#社長室」

## 7. 更新ルール

| 対象 | 誰が | いつ |
|---|---|---|
| 社長メッセージ | 社長室 | 月次 |
| 全社通達 | 社長室 | 都度 |
| 経営方針 | 社長室 | 期初、および見直し時 |
| 限定ライブラリの棚卸し | 社長室 | 年1回（4月） |
