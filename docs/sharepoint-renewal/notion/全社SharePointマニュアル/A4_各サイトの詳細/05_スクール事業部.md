# 05 スクール事業部

## 1. 何のための場所か

**個人向けスクールの募集から運営までを担い、受講者数と満足度をつくる。**

## 2. 責任と読者

| 項目 | 内容 |
|---|---|
| 責任部署 | スクール事業部 |
| サイトオーナー | スクール事業部 部長（最終責任）／運用担当 1名（**計2名以上**） |
| 想定読者 | 全社員（公開ライブラリ）／部員（限定ライブラリ）／課員（課限定ライブラリ） |
| 閲覧範囲 | 公開ライブラリは全社員、限定ライブラリは部・課のメンバー |
| 秘密度ラベル | 社外秘 |
| URL | `/sites/wb-div02` |

> 課の名称は仮です（`➀スクール運営課` / `②募集・マーケティング課`）。新組織の正式名称が決まり次第、スクール事業部が修正してください。

## 3. 書かれていること

| ページ | 中身 |
|---|---|
| ホーム | 部のミッション、**引き受けること・引き受けないこと**、体制図、**問い合わせボタン**、主要リンク、新着 |
| ➀スクール運営課 | 開講スケジュール、受講者対応、教室・オンライン運営を担当。メンバーと担当領域、定例会、課への依頼窓口 |
| ②募集・マーケティング課 | 募集広告、説明会、申込導線、受講者獲得を担当。メンバーと担当領域、定例会、課への依頼窓口 |
| 業務マニュアル案内 | この部が関わる手順書へのリンク集（実体は knowledge） |
| FAQ | この部へのよくある質問と回答 |

### この部が引き受けること

- スクールの開講・日程に関する問合せ
- 受講者からの問合せのエスカレーション対応
- 募集施策・広告出稿の相談
- 業務委託講師への連絡事項の取次ぎ

### この部が引き受けないこと

- 法人向けの研修提案（→法人事業部）
- 講師そのものの採用・評価（→研修・講師統括部）
- 受講料の入金確認・請求処理（→管理部）

### 標準リードタイム（ホームに掲示）

| 依頼種別 | 一次回答 | 完了目安 |
|---|---|---|
| 開講日程の確認 | 1営業日 | 2営業日 |
| 募集施策の相談 | 1営業日 | 5営業日 |
| 受講者データの抽出 | 1営業日 | 3営業日 |

## 4. 置かれているもの

| ライブラリ | 誰が見られるか | 誰が編集できるか | 中身 |
|---|---|---|---|
| `01_公開_共通` | 全社員 | 部メンバー | 開講スケジュールと年間カレンダー、スクールのサービス説明資料、受講者アンケートの集計結果（全社共有版）、部の業務フロー図と依頼受付ルール |
| `01_公開_➀スクール運営課` | 全社員 | 部メンバー | 運営マニュアルの概要、教室・オンライン環境の案内、受講者向け配布物のテンプレート |
| `01_公開_②募集・マーケティング課` | 全社員 | 部メンバー | 募集施策の実績サマリ、広告クリエイティブの共有版、説明会の資料 |
| `02_限定_部` | 部メンバーのみ | 部メンバー | 部内会議資料、予算・実績の内訳、受講者数の推移と見込み、他部と調整中の資料 |
| `02_限定_➀スクール運営課` | 部メンバー | ➀スクール運営課メンバー | 受講者名簿、個別対応の記録、クレーム対応の経緯 |
| `02_限定_②募集・マーケティング課` | 部メンバー | ②募集・マーケティング課メンバー | 広告費の内訳、媒体別のCPA、未公開の募集施策 |

### フォルダとファイルの決まり

- フォルダは**第1階層＝年度、深さは2階層まで**
- ファイル名は `YYYYMMDD_文書種別_件名_v1.0.拡張子`
- 詳細は「A5 ファイルの扱い方」

## 5. 置かないもの

| 置かないもの | 代わりにどこへ |
|---|---|
| 進行中のタスクと期限 | Notion の依頼・タスクDB |
| 会話・相談 | Teams |
| 個人の作業中ファイル | OneDrive |
| 規程・様式の最新確定版 | 正本置き場 |
| 全社共通の手順書・FAQ | knowledge |
| 案件ごとの成果物 | 案件管理 |
| 受講者の個人情報を含む名簿の全社共有 | 課限定ライブラリに限定 |
| 業務委託者に渡す資料 | ビジネスパートナーサイト |

## 6. 問合せ窓口

| 用件 | 行き先 |
|---|---|
| 調べたい（制度・手順・様式） | この部の FAQ / knowledge / 正本置き場 |
| 相談したい（作業は発生しない） | Teams「#スクール事業部-相談」 |
| 作業をお願いしたい（正式依頼） | ホームの**問い合わせボタン** → Notion Form（宛先＝スクール事業部） |
| 依頼の進捗を見たい | Notion 依頼・タスクDB |

## 7. 更新ルール

| 対象 | 誰が | いつ |
|---|---|---|
| ホーム・課ページ | 部の運用担当 | 内容が変わったとき／最低でも半期に1回 |
| FAQ | 部の運用担当 | 四半期ごと（Notionの依頼データを見て頻出を追加） |
| 標準リードタイム | 部長 | 半期ごと |
| 限定ライブラリの棚卸し | 部の運用担当 | 年1回（4月） |
| このページ自体 | 部のサイトオーナー | 年1回（4月）の全社棚卸しにあわせて |
