# 04 法人事業部

## 1. 何のための場所か

**法人顧客に研修・サービスを提供し、法人領域の売上をつくる。**

## 2. 責任と読者

| 項目 | 内容 |
|---|---|
| 責任部署 | 法人事業部 |
| サイトオーナー | 法人事業部 部長（最終責任）／運用担当 1名（**計2名以上**） |
| 想定読者 | 全社員（公開ライブラリ）／部員（限定ライブラリ）／課員（課限定ライブラリ） |
| 閲覧範囲 | 公開ライブラリは全社員、限定ライブラリは部・課のメンバー |
| 秘密度ラベル | 社外秘 |
| URL | `/sites/wb-div01` |

> 課の名称は仮です（`➀営業課` / `②カスタマーサクセス課`）。新組織の正式名称が決まり次第、法人事業部が修正してください。

## 3. 書かれていること

| ページ | 中身 |
|---|---|
| ホーム | 部のミッション、**引き受けること・引き受けないこと**、体制図、**問い合わせボタン**、主要リンク、新着 |
| ➀営業課 | 新規法人の開拓、提案、見積、受注までを担当。メンバーと担当領域、定例会、課への依頼窓口 |
| ②カスタマーサクセス課 | 受注後の顧客対応、継続契約、アップセルを担当。メンバーと担当領域、定例会、課への依頼窓口 |
| 業務マニュアル案内 | この部が関わる手順書へのリンク集（実体は knowledge） |
| FAQ | この部へのよくある質問と回答 |

### この部が引き受けること

- 法人顧客向けの提案書・見積の作成支援
- 法人顧客への研修プログラムの引き合い対応
- 既存法人顧客への案内・アップセルの相談
- 法人領域の市況・競合情報の共有

### この部が引き受けないこと

- 個人向けスクールの募集・運営（→スクール事業部）
- 講師のアサインと稼働調整（→研修・講師統括部）
- 契約書の法務チェック（→管理部）

### 標準リードタイム（ホームに掲示）

| 依頼種別 | 一次回答 | 完了目安 |
|---|---|---|
| 提案書レビュー | 1営業日 | 3営業日 |
| 見積作成 | 1営業日 | 3営業日 |
| 顧客向け資料の英訳 | 2営業日 | 5営業日 |

## 4. 置かれているもの

| ライブラリ | 誰が見られるか | 誰が編集できるか | 中身 |
|---|---|---|---|
| `01_公開_共通` | 全社員 | 部メンバー | 法人向けサービスの説明資料、提案書・見積書のテンプレート、受注・失注の振り返り資料、部の業務フロー図と依頼受付ルール |
| `01_公開_➀営業課` | 全社員 | 部メンバー | 営業活動で使う標準提案資料、業種別の提案事例（顧客名を伏せたもの） |
| `01_公開_②カスタマーサクセス課` | 全社員 | 部メンバー | 導入後の運用ガイド、活用事例、更新案内のテンプレート |
| `02_限定_部` | 部メンバーのみ | 部メンバー | 部内会議資料、予算・実績の内訳、パイプライン全体、他部と調整中の資料 |
| `02_限定_➀営業課` | 部メンバー | ➀営業課メンバー | 顧客個社ごとの提案・見積の作業版、商談メモ、原価の検討資料 |
| `02_限定_②カスタマーサクセス課` | 部メンバー | ②カスタマーサクセス課メンバー | 顧客個社ごとの契約情報、更新交渉の記録、解約リスクの評価 |

### フォルダとファイルの決まり

- フォルダは**第1階層＝年度、深さは2階層まで**
- ファイル名は `YYYYMMDD_文書種別_件名_v1.0.拡張子`
- 詳細は「A5 ファイルの扱い方」

## 5. 置かないもの

| 置かないもの | 代わりにどこへ |
|---|---|
| 進行中のタスクと期限 | Notion の依頼・タスクDB |
| 会話・相談 | Teams |
| 個人の作業中ファイル | OneDrive |
| 規程・様式の最新確定版 | 正本置き場 |
| 全社共通の手順書・FAQ | knowledge |
| 案件ごとの成果物 | 案件管理 |
| 顧客との契約書の正本 | 正本置き場 |
| 案件ごとの納品物 | 案件管理 |

## 6. 問合せ窓口

| 用件 | 行き先 |
|---|---|
| 調べたい（制度・手順・様式） | この部の FAQ / knowledge / 正本置き場 |
| 相談したい（作業は発生しない） | Teams「#法人事業部-相談」 |
| 作業をお願いしたい（正式依頼） | ホームの**問い合わせボタン** → Notion Form（宛先＝法人事業部） |
| 依頼の進捗を見たい | Notion 依頼・タスクDB |

## 7. 更新ルール

| 対象 | 誰が | いつ |
|---|---|---|
| ホーム・課ページ | 部の運用担当 | 内容が変わったとき／最低でも半期に1回 |
| FAQ | 部の運用担当 | 四半期ごと（Notionの依頼データを見て頻出を追加） |
| 標準リードタイム | 部長 | 半期ごと |
| 限定ライブラリの棚卸し | 部の運用担当 | 年1回（4月） |
| このページ自体 | 部のサイトオーナー | 年1回（4月）の全社棚卸しにあわせて |
