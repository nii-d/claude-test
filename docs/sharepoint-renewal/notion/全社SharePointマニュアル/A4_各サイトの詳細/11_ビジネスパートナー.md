# 11 ビジネスパートナー

## 1. 何のための場所か

**業務委託者（講師など）に、必要な情報だけを渡す場所。関係者外秘エリアの唯一のサイト。**

## 2. 責任と読者

| 項目 | 内容 |
|---|---|
| 責任部署 | スクール事業部 |
| サイトオーナー | スクール事業部 2名 |
| 想定読者 | 社員（担当者）＋ 招待した業務委託者 |
| 閲覧範囲 | `SG-BP-Partners` グループに入っている人のみ |
| 秘密度ラベル | **関係者外秘**（外部共有を許可する唯一のサイト） |
| URL | `/sites/bp-portal` |

## 3. 書かれていること

| ページ | 中身 |
|---|---|
| はじめに（パートナー向けTOP） | このサイトの使い方、連絡先、今月のお知らせ |
| 業務の進め方 | 受託業務の流れ、提出物と締切、報酬の締め日 |
| FAQ | 業務委託者からのよくある質問 |

## 4. 置かれているもの

| ライブラリ | 誰が見られるか | 誰が編集できるか | 中身 |
|---|---|---|---|
| `01_パートナー共有` | 社員＋業務委託者 | 社員のみ | 業務手順書、教材、スケジュール、請求書のひな形、連絡先 |
| `02_パートナー提出` | 社員＋業務委託者 | 社員＋業務委託者 | 業務委託者からの提出物（報告書、請求書など） |

> **単価・契約条件・評価の資料はこのサイトに置きません。** 同じサイト内に置くと設定ミス1つで見えてしまいます。
> これらは研修・講師統括部または管理部の課限定ライブラリに置いてください。

## 5. 置かないもの

| 置かないもの | 代わりにどこへ |
|---|---|
| 業務委託者の単価・契約条件 | 研修・講師統括部の課限定ライブラリ |
| 業務委託者の評価記録 | 研修・講師統括部の課限定ライブラリ |
| 社員の人事情報 | 管理部の課限定ライブラリ |
| 他社パートナーの情報 | **絶対に置かない**（相互に見えます） |
| 社外秘の全社資料 | WorkBase 配下の各サイト |

## 6. 問合せ窓口

| 用件 | 行き先 |
|---|---|
| 業務委託者からの問合せ | このサイトに記載の担当者（メール） |
| 業務委託者の追加・削除 | 依頼Form（宛先＝スクール事業部・種別＝パートナー管理） |
| 権限・外部共有の設定変更 | 依頼Form（宛先＝デジタル開発部） |

## 7. 更新ルール

| 対象 | 誰が | いつ |
|---|---|---|
| お知らせ・スケジュール | スクール事業部 | 月次 |
| 教材・手順書 | 研修・講師統括部 | 改訂時 |
| **ゲストアクセスレビュー** | スクール事業部 | **四半期ごと（必須）** |
| サイト全体の棚卸し | スクール事業部 | 年1回（4月） |

> **四半期ごとのゲストアクセスレビューは必ず実施してください。**
> 契約が終了した業務委託者のアカウントが残り続けることが、このサイトの最大のリスクです。

## このサイトの設計上の注意（管理者向け）

1. **WorkBase ハブに接続しません。** 接続すると、ナビゲーションに社外秘サイトの一覧が並び、リンク先を開けなくてもサイト名から組織の内部構造が読み取れてしまいます。
2. テナント全体の外部共有設定は「既存のゲストのみ」に絞り、**このサイトだけ**を緩めます。既定を緩くして個別に締める運用は必ず漏れます。
3. 業務委託者は必ず `SG-BP-Partners` グループ経由で追加します。個人を直接サイトに追加しないでください。
4. 秘密度ラベル「関係者外秘」を適用し、非管理デバイスからは「制限付きWeb」（ダウンロード不可）にすることを検討してください。
