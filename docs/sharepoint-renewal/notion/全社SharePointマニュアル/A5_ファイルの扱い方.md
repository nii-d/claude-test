# A5 ファイルの扱い方

**誰向け**: 全社員
**所要時間**: 4分
**この章の結論**: ファイル名は `YYYYMMDD_文書種別_件名_v1.0`、フォルダは2階層まで、共有リンクは期限付き。

---

## ファイル名

```
YYYYMMDD_文書種別_件名_v1.0.拡張子
```

**例**

| 良い例 | 悪い例 |
|---|---|
| `20260401_議事録_法人事業部定例_v1.0.docx` | `議事録.docx` |
| `20260415_提案書_A社研修導入_v2.0.pptx` | `提案書（最新）_修正版_final2.pptx` |
| `20260401_様式_経費精算書_v3.0.xlsx` | `経費精算書コピー.xlsx` |

**なぜこの形式か**: 日付が先頭にあると自然に時系列で並びます。「最新」「final」「修正版」は、次の版が出た瞬間に嘘になります。

## フォルダ

- **深さは2階層まで。** 3階層を超えると誰も辿り着けません。
- 第1階層は「年度」か「業務カテゴリ」の**どちらか一方**に統一します。部ごとに選び、途中で混ぜないでください。
- 分類が足りないと感じたら、フォルダを増やすのではなく**列（メタデータ）を使ってください。** 列ならビューで絞り込めます。

## 列（メタデータ）

すべてのライブラリに、次の列があります。ファイルをアップロードしたら入力してください。

| 列名 | 選択肢・入力内容 |
|---|---|
| 文書種別 | 規程／マニュアル／様式／議事録／提案書／報告書／その他 |
| 対象年度 | 2026 / 2027 … |
| 機密区分 | 社内限定／社外秘／関係者外秘 |
| 内容オーナー | 中身に責任を持つ人（作成者とは限りません） |
| 見直し期限 | この日を過ぎたら棚卸しの対象。正本置き場では必須 |

## バージョン管理

- SharePoint は**保存するたびに自動で履歴を残します。** `v2` `v3` というファイルを別途作る必要はありません。
- ファイル名の `_v1.0` は「対外的に確定した版」を表すためのものです。社内の作業中の細かい保存は履歴に任せてください。
- 過去の版を見たいときは、ファイルを右クリック →「バージョン履歴」。

## 共有リンク

| 相手 | 使うリンク |
|---|---|
| 社内の人 | 「組織内のユーザー」リンク |
| 社外の人 | 「特定のユーザー」リンク＋**有効期限を設定**（既定は最長30日） |
| 業務委託者 | ビジネスパートナーサイトに置く。個別リンクで渡さない |

> **「リンクを知っている全員」は使わないでください。** 転送されると誰でも開けます。

## 保存期間の目安

| 文書 | 保存期間 |
|---|---|
| 規程・様式 | 廃止後も永久（バージョン履歴に残す） |
| 契約書 | 契約終了後 10年 |
| 提案書・見積 | 5年 |
| 会議資料・議事録 | 3年 |
| 作業中ファイル | 案件完了後 1年 |

期限を過ぎたものは、年1回（4月）の棚卸しで整理します。

## 個別権限は付けない

**ファイル単位・フォルダ単位で個別に権限を設定しないでください。** 権限はライブラリ単位までです。

理由: 個別権限を許すと、半年後には誰も権限の全体像を説明できなくなります。組織改編のたびに「誰が何を見られるか」を確認できなくなり、棚卸しが不可能になります。

特定の人だけに見せたい場合は、依頼Form（宛先＝デジタル開発部）から相談してください。多くの場合、ライブラリを1つ増やすほうが安全です。
