## 元案からの主な変更点

1. **サブサイトではなくハブサイト＋独立サイト**（組織改編でサイトを付け替えられるように）
2. **公開/非公開は「ページ」ではなく「ドキュメントライブラリ」で分ける**（ページに権限で守る力はない）
3. **問合せ Forms は部署別に作らず、全社1本＋分岐**（集計・保守・組織改編対応のため）

## まず決めてほしいこと

`04_移行計画と全社マニュアル.md` の「5. 決めるべきこと」を参照。特に —

1. 新組織の**課**の正式名称と数
2. **全社員に Notion ライセンス**を配るか（配らない場合は SharePoint リスト案に切り替え）
3. **Power Automate Premium** の保有状況
