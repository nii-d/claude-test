# ビュー定義

同じデータベースを目的別に「見せ方だけ変える」のがビュー。データは1つなので二重管理は起きない。

---

## 案件DB のビュー

### 1. 進捗ボード（既定ビューにする）★最重要

| 設定項目 | 値 |
|---|---|
| レイアウト | ボード |
| グループ | `ステータス` |
| 表示プロパティ | クライアント / 研修実施日 / 営業担当 / 次のアクション / 停滞アラート |
| フィルター | `ステータス` が `失注` ではない |
| 並べ替え | `研修実施日` 昇順 |

> 全案件がどの段階にあるか、この1画面で分かる。**朝会はこの画面を映して行う**。

### 2. 実施カレンダー

| 設定項目 | 値 |
|---|---|
| レイアウト | カレンダー |
| 日付プロパティ | `研修実施日` |
| フィルター | `ステータス` が `失注` ではない |

> 研修日の重複・繁忙期が一目で分かる。講師アサインの判断に使う。

### 3. 年間タイムライン

| 設定項目 | 値 |
|---|---|
| レイアウト | タイムライン |
| 表示単位 | 月 |
| 日付プロパティ | `研修実施日` |

### 4. 自分の案件

| 設定項目 | 値 |
|---|---|
| レイアウト | テーブル |
| フィルター | `営業担当` に 自分 を含む **かつ** `ステータス` が完了系ではない |
| 並べ替え | `次のアクション期限` 昇順 |

> `営業担当` をユーザー型にした場合、フィルター値に「自分」を選べる。
> 全員が同じビューを見ても各自の案件だけが表示される。

### 5. 要注意案件（停滞アラート）★

| 設定項目 | 値 |
|---|---|
| レイアウト | テーブル |
| フィルター | `停滞アラート` に `🔴` を含む |
| 並べ替え | `最終打合せ日` 昇順 |

> 「動いていない案件」だけが並ぶ。**週次でここをゼロにするのが運用のゴール**。

### 6. 実績一覧（経営報告用）

| 設定項目 | 値 |
|---|---|
| レイアウト | テーブル |
| フィルター | `ステータス` が `実施済` `請求済` `完了` のいずれか |
| グループ | `クライアント` |
| 集計 | `受注金額` の合計を表示 |

## タスクDB のビュー

### 1. 今週のタスク（既定ビュー）

| 設定項目 | 値 |
|---|---|
| レイアウト | テーブル |
| フィルター | `期限` が「今後1週間以内」 **かつ** `完了フラグ` が未チェック |
| 並べ替え | `期限` 昇順 |

### 2. 期限切れ ⚠️

| 設定項目 | 値 |
|---|---|
| フィルター | `期限切れ`（数式）が チェック済み |

### 3. 担当者別ボード

| 設定項目 | 値 |
|---|---|
| レイアウト | ボード |
| グループ | `担当者` |
| フィルター | `完了フラグ` が未チェック |

> 負荷の偏りが見える。特定の人に積み上がっていたら再配分する。

### 4. 種別別

| 設定項目 | 値 |
|---|---|
| レイアウト | ボード |
| グループ | `種別` |

## 議事録DB のビュー

### 1. 時系列（既定ビュー）

| 設定項目 | 値 |
|---|---|
| レイアウト | テーブル |
| 並べ替え | `日付` 降順 |
| 表示プロパティ | 案件 / 日付 / 種別 / 決定事項サマリー / 未決事項 |

### 2. 種別別ボード

| 設定項目 | 値 |
|---|---|
| レイアウト | ボード |
| グループ | `種別` |

> **社内MTG と社外MTG の切り替えはこのビューで行う**（DBを分ける必要はない）。

### 3. 未決事項あり ⚠️

| 設定項目 | 値 |
|---|---|
| フィルター | `未決事項` が `あり` |
| 並べ替え | `日付` 昇順 |

> 「持ち帰り」のまま放置されている論点を拾う。週次で確認する。

### 4. 案件別

| 設定項目 | 値 |
|---|---|
| レイアウト | テーブル |
| グループ | `案件` |
| 並べ替え | `日付` 降順 |

## クライアントDB のビュー

### 1. 取引先一覧（既定ビュー）

| 設定項目 | 値 |
|---|---|
| レイアウト | テーブル |
| 表示プロパティ | 業種 / 担当者名 / 取引ステータス / 案件数 / 累計受注額 / 最新案件日 |
| 並べ替え | `累計受注額` 降順 |

### 2. フォロー対象

| 設定項目 | 値 |
|---|---|
| フィルター | `最新案件日` が「1年以上前」 **かつ** `取引ステータス` が `取引中` |

> 「そろそろ声をかけるべき休眠しかけの顧客」が自動で並ぶ。

## 案件ページ内のリンクドビュー（★これが「一目で分かる」の核心）

案件ページの本文に置く、その案件専用の議事録／タスク一覧。

| 項目 | 設定 |
|---|---|
| 作り方 | 案件ページ本文で `/リンクドビュー` と入力 → 議事録DB を選択 |
| フィルター | `案件` に **このページ** を含む（`関係` フィルターで自ダイアログから選択） |
| 並べ替え | 議事録は `日付` 降順 / タスクは `期限` 昇順 |
| 表示プロパティ | 議事録：日付・種別・決定事項サマリー / タスク：担当者・期限・状態 |

> これを**案件テンプレートに組み込んでおく**と、新規案件を作った瞬間から機能する。
> 案件ページを開くだけで「経緯（議事録）」と「今やること（タスク）」が揃う状態になる。
