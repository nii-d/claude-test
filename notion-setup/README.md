# Notion 案件管理システム セットアップ一式

教育研修事業の案件（＝研修）管理を Notion で構築するための、**インポート用ファイルと手順書**です。
Notion を触ったことがない方でも、上から順に実行すれば構築できるように書いています。

**所要時間の目安：2〜3時間**（サンプルデータでの動作確認まで含む）

---

## この一式で作られるもの

```
                    ┌──────────────────┐
                    │  クライアントDB   │  会社ごとの取引履歴
                    └────────┬─────────┘
                             │ リレーション
                    ┌────────┴─────────┐
                    │     案件DB       │  ★中心。研修1本＝1レコード
                    │  （＝研修DB）     │
                    └───┬──────────┬───┘
             リレーション │          │ リレーション
             ┌───────────┴──┐   ┌───┴──────────┐
             │   タスクDB    │   │   議事録DB    │
             └──────────────┘   └──────────────┘
```

**案件ページを開くと、その案件の「経緯（議事録）」と「今やること（タスク）」が揃って表示される** —— これがゴールです。

## ファイル一覧

| ファイル | 内容 |
|---|---|
| `01_databases/01_clients.csv` | クライアントDB（サンプル3社） |
| `01_databases/02_projects.csv` | 案件DB（サンプル3件） |
| `01_databases/03_tasks.csv` | タスクDB（サンプル11件） |
| `01_databases/04_meeting_notes.csv` | 議事録DB（サンプル7件） |
| `02_property_spec.md` | 全DBのプロパティ定義書（型・選択肢・数式・ロールアップ） |
| `03_templates/project_page.md` | 案件ページ テンプレート文面 |
| `03_templates/meeting_external.md` | 議事録テンプレート（社外） |
| `03_templates/meeting_internal.md` | 議事録テンプレート（社内） |
| `03_templates/meeting_review.md` | 議事録テンプレート（実施後振り返り） |
| `04_views.md` | 作るべきビュー一覧と設定値 |
| `05_operation_rules.md` | 社内周知用の運用ルール |

> サンプルデータは架空の企業・人物です。動作確認と社内説明に使ったあと、削除して本番データを入れてください。

## ⚠️ 事前に知っておくこと

| 項目 | 内容 |
|---|---|
| CSV でできること | 列と行の取り込みまで |
| CSV でできないこと | **リレーション・ロールアップ・数式・ビュー・テンプレート**。すべて Notion 上で手作業（手順に含めています） |
| インポート順序 | **クライアント → 案件 → タスク → 議事録** の順を必ず守ること |
| 文字コード | UTF-8（BOMなし）。Excel で開くと文字化けしますが、**Notion は正しく読みます**。Excel で開いて保存し直さないでください |

## ステップ1：チームスペースを作る（10分）

1. Notion で左サイドバー下部の **「新しいチームスペース」** をクリック
2. 名前を `案件管理` にする
3. 「全員がアクセスできる」を選ぶ（機密性の高い領域は後から別途作る）
4. 作成したチームスペース内に、`データベース` というページを1枚作る（DBの置き場所）

---

## ステップ2：CSV を順番にインポート（20分）

**必ずこの順序で行ってください。**

| 順序 | ファイル | 作られるDB名（インポート後にリネーム） |
|---|---|---|
| 1 | `01_clients.csv` | クライアントDB |
| 2 | `02_projects.csv` | 案件DB |
| 3 | `03_tasks.csv` | タスクDB |
| 4 | `04_meeting_notes.csv` | 議事録DB |

### 操作手順（各ファイル共通）

1. ステップ1で作った `データベース` ページを開く
2. 左サイドバー最下部の **「インポート」** をクリック
3. **「CSV」** を選び、ファイルを選択
4. インポートされると、ファイル名のページ（＝データベース）ができる
5. ページ名を上記の「DB名」に変更する

> **なぜ順序が大事か**：後のステップでテキスト列をリレーションに変換すると、Notion が
> 「同じ名前のページ」を探して自動リンクします。参照先（クライアント→案件）が
> 先に存在していないと、リンクが張られません。

### この時点で確認すること

- [ ] 4つのDBができている
- [ ] 各DBの1列目（会社名・案件名・タスク名・タイトル）がタイトル列になっている
- [ ] 日本語が文字化けしていない

---

## ステップ3：テキスト列をリレーションに変換する（20分）★最重要

ここが仕組みの心臓部です。

### 3-1. 案件DB の「クライアント」列を変換

1. **案件DB** を開く
2. `クライアント` 列のヘッダーをクリック → **「プロパティを編集」**
3. 種類を **「リレーション」** に変更
4. リレーション先として **クライアントDB** を選択
5. **「クライアントDBにも表示する」を ON** にする ← ★双方向にするため必須
6. 逆方向のプロパティ名を `案件` にする

> **変換直後の確認**：各行の `クライアント` セルに会社名のリンクが入っているか。
> 空になっている場合は、案件CSVの会社名とクライアントDBの会社名が1文字でも違っています。
> その場合はセルを手動でクリックして選び直してください（サンプルデータでは一致を検証済みです）。

### 3-2. 同様に以下も変換

| DB | 列 | リレーション先 | 逆方向のプロパティ名 |
|---|---|---|---|
| タスクDB | `案件` | 案件DB | `タスク` |
| 議事録DB | `案件` | 案件DB | `議事録` |

すべて **「双方向に表示する」を ON** にしてください。

### この時点で確認すること

- [ ] クライアントDBを開くと `案件` 列ができ、各社の案件が入っている
- [ ] 案件DBを開くと `タスク` `議事録` 列ができ、それぞれ紐づいている
- [ ] 案件「東和製作所_ハラスメント防止研修_2026-07」に議事録が3件、タスクが4件ぶら下がっている

## ステップ4：セレクト／ステータス型に変換する（20分）

CSV ではテキストとして入っている列を、色付きの選択肢に変えます。

### 変換対象

| DB | 列 | 変換後の型 |
|---|---|---|
| 案件DB | `ステータス` | **ステータス** |
| 案件DB | `研修テーマ` | **マルチセレクト** |
| 案件DB | `講師区分` | セレクト |
| タスクDB | `状態` | **ステータス** |
| タスクDB | `種別` | セレクト |
| 議事録DB | `種別` | セレクト |
| 議事録DB | `未決事項` | セレクト |
| クライアントDB | `業種` | セレクト |
| クライアントDB | `取引ステータス` | セレクト |

操作は 3-1 と同じ（ヘッダー → プロパティを編集 → 種類を変更）です。

### 案件DBのステータスは「グループ分け」まで行う

ステータス型に変換したら、選択肢を以下の3グループに割り当ててください。

| グループ | 選択肢 |
|---|---|
| To-do（未着手） | 引合 / 提案中 |
| In progress（進行中） | 受注 / 準備中 / 実施待ち |
| Complete（完了） | 実施済 / 請求済 / 完了 / 失注 |

> サンプルにない選択肢（引合・実施待ち・完了・失注など）は、この画面で手動追加します。
> 完全な選択肢リストは `02_property_spec.md` を参照してください。

### 色の付け方（重要）

`ステータス` の色は **進行度が直感的に分かる並び**にしてください。

`引合`=グレー → `提案中`=黄 → `受注`=青 → `準備中`=青 → `実施待ち`=紫 → `実施済`=緑 → `請求済`=緑 → `完了`=緑 → `失注`=赤

## ステップ5：ロールアップと数式を追加する（30分）

`02_property_spec.md` の定義に従って追加します。ここでは要点だけ再掲します。

### 5-1. タスクDB に `完了フラグ`（チェックボックス）を追加

1. タスクDB の右端「＋」→ 名前 `完了フラグ` → 種類 **チェックボックス**
2. `状態` が `完了` の行にチェックを入れる（サンプルでは4件）

### 5-2. 案件DB に集計プロパティを追加

| プロパティ名 | 種類 | 設定 |
|---|---|---|
| 未完了タスク数 | ロールアップ | リレーション`タスク` / プロパティ`完了フラグ` / 計算`未チェックの数` |
| 最終打合せ日 | ロールアップ | リレーション`議事録` / プロパティ`日付` / 計算`最新の日付` |
| 停滞アラート | 数式 | `02_property_spec.md` の数式をコピーして貼り付け |

### 5-3. クライアントDB に集計プロパティを追加

| プロパティ名 | 種類 | 設定 |
|---|---|---|
| 案件数 | ロールアップ | リレーション`案件` / プロパティ`案件名` / 計算`元の値をカウント` |
| 累計受注額 | ロールアップ | リレーション`案件` / プロパティ`受注金額` / 計算`合計` |

### この時点で確認すること

- [ ] 案件「ABC商事_新入社員フォローアップ研修_2026-10」の未完了タスク数が **3** になっている
- [ ] 同案件の最終打合せ日が **2026-08-12** になっている
- [ ] 株式会社ABC商事 の累計受注額が **1,200,000** になっている

## ステップ6：テンプレートを登録する（30分）

### 6-1. 案件ページテンプレート

1. **案件DB** を開き、右上の「新規」ボタンの **▼（横の矢印）** をクリック
2. **「新規テンプレート」** を選択
3. テンプレート名を `【標準】研修案件` にする
4. `03_templates/project_page.md` の中身をコピーし、本文に貼り付ける

> **Markdown はそのまま貼れます。** 見出し・表・チェックボックスが自動で変換されます。

### 6-2. 議事録テンプレート（3種類）

**議事録DB** で同様に、以下の3つを作成します。

| テンプレート名 | 貼り付けるファイル |
|---|---|
| 【社外】商談・事前打合せ | `03_templates/meeting_external.md` |
| 【社内】キックオフ・定例 | `03_templates/meeting_internal.md` |
| 【振り返り】研修実施後 | `03_templates/meeting_review.md` |

> 各テンプレートの編集画面で、`種別` プロパティにあらかじめ既定値を入れておくと、
> テンプレートを選んだ瞬間に種別が入ります（例：社外テンプレートなら `クライアント商談`）。

## ステップ7：ビューを作る（30分）

`04_views.md` の定義に従って作成します。**まず以下の3つだけ作れば運用を始められます。**

1. 案件DB「進捗ボード」（ステータス別グループ）
2. タスクDB「今週のタスク」
3. 議事録DB「時系列」

残りは運用しながら追加してください。

## ステップ8：案件ページにリンクドビューを設置する（20分）★核心

「案件ページを開けば、その案件の議事録とタスクが並んでいる」状態を作ります。

1. ステップ6で作った **案件テンプレート `【標準】研修案件`** を編集モードで開く
2. 「## 4. 議事録」の下にカーソルを置き、**`/リンクドビュー`** と入力
3. **議事録DB** を選択
4. 作られたビューの **「フィルター」** → `案件` → **「このページ」** を選択
   （テンプレート内では「テンプレートのページ」という選択肢になります）
5. 並べ替えを `日付` の降順にする
6. 「## 5. タスク」の下でも同様に、**タスクDB** のリンクドビューを設置
   - フィルター：`案件` が「このページ」
   - 並べ替え：`期限` 昇順

> この設定をテンプレート側に入れておくことで、**今後作るすべての案件で自動的に機能します**。
> 既存のサンプル案件3件には、同じ操作を手動で1回ずつ行ってください。

## ステップ9：権限を設定する（20分）

### 社員（メンバー）

チームスペース `案件管理` に招待するだけで、4つのDBすべてにアクセスできます。

### 業務委託講師

**まずは Notion に招待しない**ことを推奨します。SharePoint の閲覧権限だけで足りるケースがほとんどです。

Notion 上で共有が必要になった場合のみ：

1. 案件ページ内の **「6. 講師向け共有ページ」** を、独立したサブページにする
   （見出しの左の「⋮⋮」→「ページに変換」）
2. そのサブページを開き、右上 **「共有」** → メールアドレスを入力して招待
3. 権限を **「閲覧のみ」** または **「編集可」** から選ぶ
4. 招待された人は **ゲスト**として扱われ、**有料枠を消費しません**

> ⚠️ **案件ページ全体を共有しないでください。** 受注金額・社内メモまで見えてしまいます。
> 必ず「講師向け共有ページ」だけを共有します。

## 構築後にやること

1. **サンプルデータを削除**し、進行中の実案件を2〜3件だけ登録して1か月試す
2. `05_operation_rules.md` を社内に配布し、**議事録は Notion に直接書く**ルールを周知する
3. 週次15分の定例で、`04_views.md` の「定例チェック」3ビューを確認する習慣をつける

> 最初から完璧を目指さないでください。プロパティは後からいくらでも追加できます。
> **まず回すこと**が最優先です。
